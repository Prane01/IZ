# Graco TSTK Translator Decompiled Project

## How to Decompile

### Step 1: Download CFR
Download CFR decompiler (cfr-0.152.jar) from: https://www.benf.org/other/cfr/

### Step 2: Run Script
- On **Windows**:
  ```
  cd scripts
  decompile.bat C:\path\to\cfr-0.152.jar
  ```

- On **Linux/Mac**:
  ```
  cd scripts
  ./decompile.sh /path/to/cfr-0.152.jar
  ```

### Step 3: View Source
Decompiled `.java` files will appear in:
```
src/main/java/
```
